# 持ち物見える化アプリ（試作版）

予定ごとに持ち物を洗い出し、「どのシーンで」「どの場所に」「いくつあるか」を見える化する試作版です。
既存の発音アプリとは別物で、このフォルダの中だけで完結しています。

## 開き方

`index.html` をブラウザ（Chrome / Safari）で開くだけです。インストールやサーバーは不要です。

## 今できること（第1段階：画面イメージの確認）

- 京都 2泊3日のサンプルデータを表示
- 上部のタブでシーン切り替え（12シーン）
- 場所の枠と入れ子（最大3段、3段目は最初は閉じている）、枠のタップで開閉
- 各アイテムの「未使用 / 手持ち」の数字

## 編集できること（第2段階）

- アイテムをタップ：名前、総数（＋／−）、使い方のタイプ、そのシーンで使う数（予定・当日の記録）、削除
- 場所の ✎：名前の変更（ほかのシーンの同じ名前の場所もまとめて変更できる）、削除（中身は未配置へ）
- シーン名・予定名の ✎：名前の変更
- 変更はこの端末のブラウザに保存。ページ下の「サンプルデータに戻す」で最初の状態に戻せます

## 決まったこと

- 使用の記録：案C（準備時に予定数を入れ、当日に修正できる）。データは `planned`（予定）と `actual`（当日の記録）を持ち、当日の記録があればそちらを優先して計算します。
- 試作はブラウザ版。操作感が固まったら iPhone アプリ（SwiftUI）へ移行。
- どの場所にも入っていないアイテムは各シーンの下に「未配置」として表示。
